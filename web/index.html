Private Key Converter

Bitcoin WIF ↔ raw private key, with derived Bitcoin and Ethereum addresses.

Network/compressed only apply when the input is raw hex — pasting a WIF uses the network and format already encoded in it.

Everything runs locally in your browser via WebAssembly — nothing you type is sent anywhere. For real keys, download this project and run it offline: open web/index.html served from a local static server with no network connection.
